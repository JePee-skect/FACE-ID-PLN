# ⚡ PLN PUSHARLIS - Face ID Presensi (E-Absensi)

Aplikasi Web Presensi Biometrik Wajah Cerdas bertema **PT PLN (Persero) - Pusat Pemeliharaan Ketenagalistrikan (PUSHARLIS)** dengan mode sederhana **IN (Masuk)** & **OUT (Pulang)**.

---

## 🌟 Fitur Utama
- **Mode Sederhana IN / OUT**: Tombol besar yang jelas untuk beralih antara Absen Masuk dan Absen Pulang.
- **Biometrik AI & Liveness Anti-Spoofing**: Mendeteksi wajah secara real-time dan mencegah kecurangan menggunakan foto cetak atau layar HP.
- **Sambutan Suara Bahasa Indonesia**: Mengumumkan nama pegawai saat absen masuk/pulang berhasil.
- **Pendaftaran Pegawai Baru**: Ambil foto wajah via webcam langsung dan simpan NIP/Bidang.
- **Unduh Laporan Excel / CSV**: Ekspor riwayat presensi harian langsung ke file CSV.
- **Ringan & Cepat (Zero-Dependency)**: Berjalan langsung dengan Node.js standar.

---

## 🚀 Cara Menjalankan
Cukup klik ganda (double-click) file:
```
start.bat
```
Browser akan otomatis terbuka dan memuat aplikasi di:
```
http://localhost:3001
```
